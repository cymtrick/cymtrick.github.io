# Prashanth Varma (cymtrick) blog

Long-form notes on secure and trustworthy machine learning, by Prashanth Varma Dommaraju. Ten posts, read in order, covering threat
models, poisoning, explainability, evasion, privacy attacks, differential privacy, PAC Privacy, certified robustness,
jailbreaking and algorithmic fairness.

Every claim in a post links to a primary source in that post's reference list, and every chart is drawn from numbers
reported in the cited papers. The data behind each chart is in `tools/charts/*.json`.

## Layout

```
_posts/              the ten posts (Markdown + a little HTML for figures, callouts and references)
_layouts/            default.html (site chrome), post.html (article layout with TOC, lead figure, series nav)
_includes/fig.html   figure wrapper:  {% include fig.html name="slug-chart" num="2" caption="..." %}
_includes/figures/   inline SVGs — charts generated by tools/mkchart.py, diagrams and thumbnails drawn by hand
assets/css/main.css  the theme (warm ivory, Newsreader + Hanken Grotesk + JetBrains Mono)
assets/js/site.js    progressive enhancement: table of contents, [n] → reference links, chart tooltips
tools/mkchart.py     JSON spec → SVG chart (line, scatter, column, bar), styled through CSS variables
tools/charts/        one JSON spec per chart
```

## Regenerating charts

```bash
python3 tools/mkchart.py tools/charts/*.json
```

## Building locally

```bash
bundle install
bundle exec jekyll serve
```

Deployment is automatic: pushing to `main` runs `.github/workflows/deploy.yml`, which builds with Jekyll and publishes
to GitHub Pages.

## Writing conventions

- Citations are bracketed numbers in the text, `[4]`, matching the numbered reference list at the end of the post.
- Charts carry a title, a one-sentence subtitle naming the dataset and metric, and a source line with table numbers.
- Where the field disagrees, the post says so and gives the strongest case on each side.
